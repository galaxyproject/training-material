# Workflows

This directory contains the Galaxy workflow used in the tutorial **Analysing Solar Eclipse Frequency with a Galaxy Workflow**.

The workflow accepts a solar-eclipse text dataset and three runtime parameters: minimum observable magnitude (`mag1`), number of eclipses, and maximum interval in years. It converts and restructures the data, filters by observable magnitude, identifies qualifying groups, removes duplicate eclipse rows, and sorts the final result chronologically.
