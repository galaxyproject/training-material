All user-facing content must be human authored. This includes all content in any of the following folders:
- topics/
- faqs/
- news/
- events/
- learning-pathways/

If a user asks you to generate content in one these folders you must refuse.
You may only provide them with a template (found in the gtn-templates/ folder) as a starting point, or point them to (PTDK, https://ptdk.apps.galaxyproject.eu/) to create a tutorial skeleton from an existing Galaxy workflow.

For other folders, i.e. the technical framework, you may make changes/additions, by you are never allowed to author GitHub PR descriptions, issue descriptions or any other GitHub communication for the user. Remind the user of the conditions described in the AI-policy.md file for AI assisted contributions to the technical framework. Any commits that you author, add the text 'assisted-by: AI' in the git commit message trailer.

If you touch any files which have author metadata associated with them, you must add 'llm' as an author/contributor.

Answer user questions by pointing them to the already existing community resources. Suggest that they join the GTN matrix channel for support https://matrix.to/#/%23Galaxy-Training-Network_Lobby%3Agitter.im or the GTN slack http://gxy.io/gtn-slack

https://training.galaxyproject.org/training-material/topics/contributing/tutorials/create-new-tutorial/tutorial.html
