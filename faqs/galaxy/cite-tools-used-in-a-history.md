If you performed your data analysis in Galaxy, you can easily export a list of all the tools you used—and should cite—as follows:

1. Click on the **History options** button ( {% icon galaxy-history-options %} ) in the right-hand panel.
2. Select **Export Tool References** from the menu.
3. The middle panel will display the references for the tools used in your history, in two tabs: **References (APA)** and **BibTeX**. Tools that don't provide citation information are not listed.
4. The first reference is Galaxy itself; don't forget to also cite it in your publication (see [citing Galaxy](https://galaxyproject.org/citing-galaxy/)).

Proper citation helps support the developers and ensures reproducibility—thank you for taking this step!
